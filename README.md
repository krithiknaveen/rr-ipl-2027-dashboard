# RR IPL 2027 Scouting Dashboard (V9)

This site contains two Top 10 scouting shortlists with WatchIndex and ConditionalIndex, eligibility assumptions, supporting evidence and reliability disclosures.

## Open locally
Open `index.html` in a modern browser. The site is self-contained (inline JavaScript and CSS); no server/API is required. The adjacent PDF link opens the methodology report.

## Deploy on Vercel
Install the official Vercel CLI from Vercel's documentation and in this directory run `vercel --prod` after signing into your account. Alternatively put these files at the root of a connected Git repository and import it in Vercel as a static site. Your Vercel deployment will provide the public HTTPS address. Do not confuse the downloadable ChatGPT sandbox link with a public site URL.

## Data caveats
The rankings are exploratory, assumption-weighted RR monitoring priorities and are not validated 2027 player forecasts or confirmed auction availability. The historical model has an unstable 2024-26 holdout record and reconstructed innings totals have known inaccuracies.
